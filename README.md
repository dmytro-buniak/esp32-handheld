# 🔧 ESP32 Handheld

**3D-printed enclosure for a battery-powered ESP32 handheld: 0.96" OLED, four tact switches, Li-ion cell with TP4056 charging and a magnetic pogo-pin connector. Designed in FreeCAD.**
